A and B are timed in separate
              processes, so the gap between them carries run-to-run noise. The
              control's A/A ratio has a true value of 1.000x, so
              whatever it comes back as is the bar an A-vs-B difference has to clear
              before it means anything. Every A/B script in scripts/
              prints the same column, and csrc/TUNING.md puts the floor
              near 4.3%. Across many shapes it runs once per shape, because the
              floor belongs to the shape — a 32-token sequence is far noisier
              than a long one.
