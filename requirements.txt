# Python dependencies for torch_transformer_benchmark.py
#
#     pip install -r requirements.txt
#
# Everything else the project imports (argparse, http.server, json, math, os,
# statistics, subprocess, time, dataclasses, typing) ships with the standard
# library -- including the dashboard, which adds no dependencies of its own.
# The one exception is matplotlib, at the bottom, which only the two chart
# scripts use.
#
# The line below points pip at PyTorch's own package index so it installs a
# build with GPU support. Plain PyPI gives the default build, which on Windows
# is CPU-only and cannot run any of this. Change cu132 to match your CUDA
# Toolkit if it is not 13.x -- a mismatch between the wheel and the local
# toolkit is the usual cause of extension build failures.
--extra-index-url https://download.pytorch.org/whl/cu132

# Required. Developed and tested against 2.12.0+cu132.
torch>=2.12

# Required. torch.utils.cpp_extension uses ninja to compile the CUDA kernels in
# csrc/ on first use. There is no prebuilt-attention fallback: if the extension
# does not build, the benchmark raises rather than measuring something else.
ninja

# Only needed to regenerate the charts in images/ -- scripts/plot_speedups.py
# and scripts/plot_ledger_progress.py, which draw speedup-by-shape.png and
# geomean-by-iteration.png. Nothing in the benchmark, the kernels, the
# verification scripts or the dashboard imports it, so a run that only measures
# does not need it installed.
matplotlib
